## 📦 ЧТО РЕАЛИЗОВАНО

### ✅ 1. Spring Boot приложение
- REST API для навигации по кампусу
- Endpoints:
  - `GET /api/navigation/` - Welcome message
  - `POST /api/navigation/route` - Расчет маршрута
  - `GET /api/navigation/location/{id}` - Информация о локации
  - `GET /actuator/health` - Health check
- База данных: H2 (in-memory)
- Порт: 8888
