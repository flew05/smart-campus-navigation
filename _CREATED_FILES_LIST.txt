📋 PIPELINE STAGES
=================================================================

1. Checkout          → Git clone кода
2. Build             → Компиляция (mvn compile)
3. Unit Tests        → Запуск тестов (mvn test)
4. SonarQube         → Анализ качества кода
5. Quality Gate      → Проверка стандартов
6. Package           → Создание JAR (mvn package)
7. Deploy to Nexus   → Загрузка артефакта в Nexus
8. Deploy App        → Развертывание приложения
9. Health Check      → Проверка работоспособности

🎯 СЛЕДУЮЩИЕ ШАГИ
=================================================================

ЛОКАЛЬНЫЙ ЗАПУСК:
  1. mvn clean package
  2. java -jar target/smart-campus-navigation-1.0.0-SNAPSHOT.jar
  3. curl http://localhost:8888/api/navigation/

CI/CD PIPELINE:
  1. git init && git add . && git commit -m "Initial commit"
  2. git remote add origin <your-git-url>
  3. git push -u origin main
  4. Настроить Jenkins (см. JENKINS_SETUP_INSTRUCTIONS.md)
  5. Запустить Build Now в Jenkins

DOCKER:
  1. docker-compose up -d
  2. curl http://localhost:8888/api/navigation/
