@startuml Smart_Campus_Navigation_System

' Определяем актёров
actor Student
actor Visitor
actor "Faculty/Staff" as Faculty
actor "Campus Information\nSystem" as CampusInfo

' Определяем system boundary
rectangle "Smart Campus Navigation System" {
  
  ' Use Cases для Student
  usecase "Receive Notifications" as UC1
  usecase "View Schedule-Based\nRoute" as UC2
  usecase "Search Campus\nFacilities" as UC3
  usecase "Navigate to Location" as UC4
  
  ' Вспомогательные use cases
  usecase "Calculate Route" as UC5
  
  ' Use Cases для Faculty/Staff
  usecase "Update Room\nInformation" as UC6
  
  ' Use Cases для Campus Information System
  usecase "Provide Schedule Data" as UC7
  
}

' Связи актёров с use cases
Student --> UC1 : uses
Student --> UC2 : uses
Student --> UC3 : uses
Student --> UC4 : uses

Visitor --> UC3 : uses
Visitor --> UC4 : uses

Faculty --> UC4 : uses
Faculty --> UC6 : uses

CampusInfo --> UC7 : provides

' ПРАВИЛЬНЫЕ RELATIONSHIPS:

' Include: Navigate to Location включает Calculate Route
UC4 .> UC5 : <<include>>

' Extend: View Schedule-Based Route расширяет Receive Notifications
' ПРАВИЛЬНОЕ НАПРАВЛЕНИЕ: от расширяющего К базовому
UC2 .> UC1 : <<extend>>

@enduml

ПОДРОБНОЕ ОБЪЯСНЕНИЕ ПРАВИЛЬНЫХ НАПРАВЛЕНИЙ
═══════════════════════════════════════════════════════════════════════════════

📖 ПРАВИЛА UML ДЛЯ СТРЕЛОК:

1. <<include>> - "базовый use case ВКЛЮЧАЕТ вспомогательный"
   ─────────────────────────────────────────────────────────
   Стрелка идет ОТ базового (Navigate to Location) 
                К включаемому (Calculate Route)
   
   Логика: "Navigate to Location всегда требует Calculate Route"
   Направление: [Navigate] --include--> [Calculate]


2. <<extend>> - "расширяющий use case РАСШИРЯЕТ базовый"
   ─────────────────────────────────────────────────────────
   Стрелка идет ОТ расширяющего (View Schedule-Based Route)
                К базовому (Receive Notifications)
   
   Логика: "View Schedule-Based Route опционально добавляет функциональность 
            к Receive Notifications (когда уведомление связано с расписанием)"
   Направление: [View Schedule] --extend--> [Receive Notifications]


⚠️ ТВОЯ ОШИБКА НА ДИАГРАММЕ:
   У тебя стрелка шла: Receive Notifications --extend--> View Schedule-Based Route
   Это НЕПРАВИЛЬНО! Стрелка должна идти в обратную сторону.
