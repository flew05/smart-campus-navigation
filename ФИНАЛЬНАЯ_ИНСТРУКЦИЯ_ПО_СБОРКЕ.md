Function 2.1 - Use Guest Mode (Updated):
This is not an automatic fallback for failed authentication. When authentication

**ДОПОЛНИТЕЛЬНЫЙ ТЕКСТ ПРО ACKNOWLEDGE:**

```
The "acknowledge" action represents explicit user interaction with the 
notification. Implementation options include:
a) User taps a "Got it" or "OK" button within the notification detail screen
b) Dismissing the notification after viewing details
c) Taking action (e.g., starting navigation to new room)

The Mobile App logs this acknowledgment with timestamp and sends confirmation 
to the backend. This serves multiple purposes: confirms message delivery for 
critical notifications (room changes, emergencies), provides analytics on 
notification effectiveness, and allows instructors/administration to track 
which students have been informed of important changes. For non-critical 
notifications, implicit acknowledgment (viewing the notification) may be 
sufficient.
```
